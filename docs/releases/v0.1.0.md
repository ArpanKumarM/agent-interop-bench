# Agent Interop Bench v0.1.0

**Phase 1: an MCP evaluation engine.**

Agent Interop Bench tests whether an AI agent selects the correct tools,
supplies valid arguments, handles failures gracefully, resists malicious
tool output, and recovers safely — deterministically, without an LLM judge.
This first release covers MCP end to end; A2A support is planned but not
yet implemented.

## What's in this release

- **A local, offline mock MCP server** exposing four tools
  (`search_issues`, `get_repository`, `create_comment`, `calculate_sum`)
  with configurable failure injection: timeouts, exceptions, malformed
  responses, and prompt-injection payloads. It never calls real GitHub or
  the network.
- **19 deterministic benchmark cases** exercising correct and incorrect
  tool selection, valid and invalid arguments, a hallucinated tool,
  timeouts, tool exceptions, malformed responses, prompt injection, and
  both approved and unapproved mutating actions.
- **8 deterministic evaluators** — tool selection accuracy, argument
  correctness, schema validity, task completion, error handling, timeout
  recovery, unsafe-action detection, and prompt-injection resistance. No
  LLM is used as a judge; every verdict is reproducible. See
  [`docs/scoring.md`](../scoring.md) for exact scoring rules.
- **A runner-enforced safety gate**: mutating tools only execute when a
  benchmark case explicitly grants approval — never based on the agent's
  own say-so.
- **A pluggable `AgentAdapter` interface** with a deterministic fake
  adapter, so the full suite and CI run with zero API keys and zero
  network access. A `PlaceholderAdapter` documents the future real-model
  integration point.
- **A FastAPI service** (`/health`, `/tools`, `/benchmarks`, `POST /runs`,
  `/runs/{id}`, `/runs/{id}/report`) with an in-memory run store behind a
  swappable repository interface.
- **Docker Compose** one-command startup and a **`scripts/demo.sh`**
  end-to-end demo that starts the stack, runs the suite, and cleans up
  after itself automatically.
- **47 passing tests** (unit + integration), all offline; CI runs lint,
  format checks, and the full suite on every push.

## Try it

```bash
git clone https://github.com/ArpanKumarM/agent-interop-bench.git
cd agent-interop-bench
./scripts/demo.sh
```

## Known limitations

- Prompt-injection resistance is scored for a single-step runner: the
  agent decides its action before seeing tool output, so this measures
  detection-and-non-deviation, not multi-turn resistance.
- Run storage is in-memory only and does not persist across restarts.
- `POST /runs` runs synchronously; there is no background job queue yet.
- No real LLM-backed adapter is wired up yet.
- A2A agent support is not implemented in this release.
