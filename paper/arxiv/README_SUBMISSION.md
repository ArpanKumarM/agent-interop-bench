# arXiv submission notes

Self-contained arXiv-ready LaTeX source for **"Public-Sharing Labels and
Verbatim Field Egress in an MCP-to-A2A Agent Configuration: A Controlled
Multi-Model Study."** Proposed metadata (title, authors, abstract,
comments, category, license): [`ARXIV_METADATA.txt`](ARXIV_METADATA.txt).

Every numeric table body and figure datum is machine-generated by
`gen_tables.py` from the frozen analysis artifacts (`reports/…`, released
separately) and re-verified by `audit_numbers.py`; nothing is
hand-transcribed. Manuscript preparation made zero provider calls and
changed no raw observation, stimulus, schedule, model, parameter, outcome
definition, or analysis plan. Phase 6 and Phase 7 observations are never
pooled.

## Build

```
uv run python paper/arxiv/gen_tables.py               # rewrite generated/*
bash        paper/arxiv/build_pdf.sh                  # deterministic PDF (SOURCE_DATE_EPOCH)
uv run python paper/arxiv/audit_numbers.py            # fails on any stale/inconsistent number
uv run python paper/arxiv/build_arxiv_submission.py   # minimal upload archive
```

Compiled PDF: **12 pages**, TeX Live 2026, `pdflatex` + `bibtex`; 0
undefined citations, 0 undefined references, 0 overfull `\hbox`. The date
is a literal (`\date{August 2026}`, no `\today`); with
`SOURCE_DATE_EPOCH=1451606400` the PDF is byte-reproducible.

## Minimal upload archive

`arxiv-submission.tar.gz` (built by `build_arxiv_submission.py`; sorted
members, `mtime=0`, mode `0444`, `uid=gid=0`, gzip `mtime=0`) contains
**only** what arXiv needs to compile `main.tex`:

| file(s) | why required |
|---|---|
| `main.tex` | the manuscript |
| `references.bib` | bibliography database for `\bibliography{references}` |
| `main.bbl` | pre-generated bibliography (arXiv compiles from `.bbl`) |
| `generated/p7_arms.tex`, `p7_contrasts.tex`, `p7_diag.tex`, `p6p7_cp.tex`, `rq2_model.tex`, `exec_integrity.tex`, `p7_scen_cn.tex`, `p7_scen_pn.tex`, `p7_scen_cp.tex`, `pinned_ids.tex` | the 10 table bodies `\input` by `main.tex` |
| `generated/p7_cn_scatter.dat`, `p7_cn_means.dat`, `p7_pn_scatter.dat`, `p7_pn_means.dat` | the 4 pgfplots data files loaded by the figure's `\addplot table{...}` |

Packages (all standard TeX Live, no bundled `.sty`/`.cls`): `fontenc`,
`inputenc`, `lmodern`, `geometry`, `amsmath`, `amssymb`, `array`,
`booktabs`, `microtype`, `url`, `caption`, `pgfplots` (`compat=1.18`),
`natbib`, `hyperref`. The only figure is drawn inline with `pgfplots`, so
there is **no image file and no `\includegraphics`**. No shell-escape, no
network access, no absolute paths.

**Not** in the archive (not compile inputs): `gen_tables.py`,
`audit_numbers.py`, `build_*.py`, `ARXIV_METADATA.txt`, this file,
`main.pdf`, `generated/facts.json`, `generated/rq2_diag.tex`, and anything
under `reports/`, `tests/`, or the rest of the repository.

Compilation from a clean extraction:

```
pdflatex main
bibtex   main
pdflatex main
pdflatex main
```

Verified to reproduce the repository PDF byte-for-byte from an empty
directory with no other repo access.
