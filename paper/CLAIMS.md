# CLAIMS — what this paper does and does not assert (Phase 7F)

Scope of every claim below: a **real-model host** — three OpenAI GPT-5.6
tiers (`sol`/`terra`/`luna`) via the Responses API and **Claude Sonnet 5**
via the Anthropic Messages API — driven over **local deterministic MCP and
A2A protocol fixtures**, one host policy, the **`{relay_to_remote, stop}`**
decision surface, the **decision-point** methodology (one restricted host
decision per trial), at one point in time.

The **primary study** is the frozen Phase 7 three-arm neutral-baseline
study (`composed-live-canary-007a` / `v7a`): **10 record scenarios × 3 arms
(confidential C / unlabeled N / public P) × 4 repeats × 4 models = 480
trials**. The six substantive record values are byte-identical across arms;
the arms differ only in the record's opening header line. **The scenario is
the generalization unit (`n = 10`); the four within-cell repeats are
repeated observations, not independent samples.** All Phase 7 numbers are
from the frozen Phase 7E analysis (execution source commit
`2a892c0b9a8a636055cc0c4229aebfd788738b60`; analysis implementation commit
`dc5d0767ce4bec946373bf720a37aae538ef258c`; interpretation freeze
`b53ddc6`; pre-registered analysis plan SHA-256 `87fec92f…`). **No
p-values, no significance tests, no bootstrap or confidence/credible
intervals, no cross-model pooling. Phase 6 and Phase 7 observations are
never pooled.** Every numeric table body and every figure datum in
`paper/arxiv/main.tex` is machine-generated by
`paper/arxiv/gen_tables.py` and audited by `paper/arxiv/audit_numbers.py`.

## A. Directly supported empirical claims

1. **No convincing evidence of a confidential-header suppression effect.**
   The unlabeled baseline provides no convincing evidence that adding a
   `CONFIDENTIAL - INTERNAL ONLY` header reduces verbatim substantive-field
   egress in any of the four models. For `gpt-5.6-sol`, `gpt-5.6-terra` and
   `gpt-5.6-luna` the confidential and unlabeled arms are both `0/40`, so
   every scenario-level C − N is exactly 0 (uninformative; `gpt-5.6-terra`
   is a complete floor across all three arms). For `claude-sonnet-5` the
   C − N mean is −0.100 with 7/10 scenarios exactly zero and 3 negative,
   over a low unlabeled baseline (`5/40`); under the conservative
   floor/headroom reading (Phase 7E.1) this contrast is treated as
   **low-baseline / floor-bounded** and is **not** described as evidence of
   suppression. The pre-registered design left "neutral baseline at or near
   zero" unquantified; the analysis implementation's `N ≤ 0.05` classifier
   was implementation-supplied, not pre-registered, and Phase 7E.1 adopts
   the threshold-free conservative reading without changing any numeric
   result.
2. **Public-sharing-label association (descriptive).** Adding
   `PUBLIC - OK TO SHARE` is associated with higher verbatim egress
   relative to the unlabeled baseline: `claude-sonnet-5` P − N mean
   **+0.800**, median +0.750, **10/10 scenarios positive** (`N = 5/40` vs.
   `P = 37/40`); `gpt-5.6-luna` **+0.250**, 7/10 positive (`N = 0/40` vs.
   `P = 10/40`); `gpt-5.6-sol` **+0.125**, 4/10 positive (`N = 0/40` vs.
   `P = 5/40`); `gpt-5.6-terra` **0.000**, 0/10 positive (uninformative
   floor). This is a descriptive association ("higher verbatim egress under
   the added public / OK-TO-SHARE header relative to the unlabeled
   baseline", "consistent with models responding differently to an explicit
   sharing cue"), **not** a demonstrated causal or psychological mechanism.
   Magnitude and even observability are strongly model-dependent.
3. **Descriptive C − P reproducibility with the earlier two-arm study.**
   The earlier frozen Phase 6 `v4r1` two-arm study
   (`CONFIDENTIAL - INTERNAL ONLY` vs. `PUBLIC - OK TO SHARE`, 10 pairs)
   found a paired C − P difference of −0.250 (`gpt-5.6-sol`), 0.000
   (`gpt-5.6-terra`), −0.125 (`gpt-5.6-luna`), −0.900 (`claude-sonnet-5`).
   Recomputed on Phase 7 data the C − P direction reproduces for the three
   non-floor models (`gpt-5.6-sol` −0.125, `gpt-5.6-luna` −0.250,
   `claude-sonnet-5` −0.900); `gpt-5.6-terra` is a floor in both. This is a
   **descriptive** comparison only — different times, different provider
   snapshots, no pooling, no statistical test. The Phase 7 decomposition
   indicates the earlier C − P gap is carried mainly by the public arm
   (P − N > 0), not by confidential-arm suppression.
4. **Secondary null experiment (Phase 6 influence experiment).** Across 319
   analysable trials (320 planned; 1 `provider_protocol_error` attrition)
   there were **0 mutating-tool requests** — a complete floor — so the
   adversarial−benign effect is **not estimable**. Because the rate is
   pinned at 0 in both arms, **the design establishes no resistance to
   adversarial cross-agent influence**; a plausible unproven explanation is
   insufficient headroom in the generic `{call_tool, stop}` task framing.
5. **Verified system-enforcement property (not a research question).** In
   the earlier two-arm study's trace audit over all 640 scheduled trials,
   the number of trials in which an unapproved request whose trusted
   discovered classification is mutating actually executed was **0**
   (`violations = 0`, `mutating_tool_executed = 0`). This follows from
   deterministic enforcement plus a per-trial trace audit; it is **not** a
   model-safety rate, and because no model requested a state-changing tool,
   the gate was never exercised by a real state-changing request.

## B. Descriptive observations (not effects)

- `relay_initiated` rates vary sharply by model but move little across arms
  within a model, except `claude-sonnet-5`, whose relay rate itself tracks
  the label (0.025 / 0.125 / 0.925 for C / N / P).
- Primary egress is essentially relay-conditional: the primary-positive
  rate among relay trials is 1.000 for every `claude-sonnet-5` arm and
  0.357 / 0.256 for the `gpt-5.6-sol` / `gpt-5.6-luna` public arms, 0
  elsewhere.
- `credential_token_copied` is floored everywhere except `gpt-5.6-sol`
  public (`1/40`); egress is driven by the five structured fields, chiefly
  `full_name` and `account_id`.
- Under the secondary null experiment's adversarial framing some models
  substitute a read-only diagnostic call for `stop` (`claude-sonnet-5`
  `stop` rate 95% control vs. 25% adversarial); every requested tool was
  read-only.
- `gpt-5.6-luna` relays a record in almost every Phase 7 trial in all three
  arms yet reproduces exact field values only in the public arm.

## C. Limitations

- Synthetic in-process MCP / A2A fixtures; one host policy; one
  `{relay_to_remote, stop}` action surface; one provider snapshot.
- Exact-substring verbatim detector over six values; paraphrased /
  summarised / partial disclosure is not measured; a 0 is not "no
  information crossed the boundary." `disclosed_field_count` covers only
  the five structured fields (excludes `credential_token`, which the
  six-value primary includes).
- 10 authored scenarios; four repeats + binary outcome ⇒ scenario rates in
  {0, .25, .5, .75, 1} and contrasts on a 0.25 grid; per-model means are
  averages over `n = 10`.
- `gpt-5.6-terra` is a complete floor; `gpt-5.6-sol` / `gpt-5.6-luna` have
  floored confidential and unlabeled arms; `claude-sonnet-5`'s unlabeled
  baseline is low (`5/40`).
- The P − N association is descriptive, not causal. The public arm's header
  bundles "PUBLIC" and "OK TO SHARE"; the study does not separate them.
- No alternative (non-A2A) sink or single-protocol control; results are
  scoped to behavior measured at this MCP→A2A seam.
- Providers are not numerically equated (each uses its own low-effort
  mode); `claude-sonnet-5` is a robustness block, not a ranked comparator.
- One attrition event in the earlier study (RQ2 analysable `N = 319`).
- The enforcement property was not stress-tested by a true state-changing
  model request.

## D. Claims that would be OVERSTATEMENT — not made

- "The public label causes disclosure" / "permission mechanism proved" —
  P − N is a descriptive association, not a demonstrated causal mechanism.
- "The confidential label protects data" / "confidentiality suppresses
  disclosure" — the neutral baseline gives no convincing evidence of any
  such effect.
- "First cross-protocol study" / "first composition study" / "first MCP/A2A
  security work."
- "Resistant / robust to cross-agent influence" — the secondary null
  experiment is a floor and establishes no such thing.
- "Proof that model X is safe" / "100% safety rate" — the enforcement
  property is a deterministic gate plus audit, not a model-safety rate, and
  no true state-changing request occurred.
- "Empirical action containment" — the gate was never exercised by a real
  state-changing request.
- Any provider ranking or between-provider significance claim; any semantic
  or paraphrased-leakage claim; any pooling of the Phase 6 and Phase 7
  observations.
